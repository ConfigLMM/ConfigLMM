# Vision

## Why this project exists

Modern infrastructure and application operations often require many disconnected tools, formats, and platform-specific workflows.

ConfigLMM is intended to reduce that fragmentation by providing:

- a higher-level configuration model,
- a shared CLI lifecycle (validate/build/deploy/refresh/test/etc.),
- plugin-based implementations for specific services, platforms, and OS targets.

The goal is to describe intent first, while keeping implementation details inside plugins.

## Long-term direction

The long-term idea is broad: one ecosystem that can model and operate many types of systems without locking users into one provider or one low-level toolchain.

This vision is intentionally ambitious and community-driven.

## Important reality

The project vision is larger than the currently implemented feature set.

For current capabilities, see [current-functionality.md](current-functionality.md).
